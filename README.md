## Instrucciones para agregar tus imágenes

1. **Copia tus fotos a la carpeta `images/`**
2. **Asegúrate que los nombres sean exactos** (mayúsculas y minúsculas importan)
3. **Guarda las imágenes en formato JPG o PNG**
4. **Las imágenes se mostrarán automáticamente en la página**

## Cambiar el número de WhatsApp

Abre `index.html` con un editor de texto y busca `573136140489`. Reemplaza este número con tu número de WhatsApp (incluye el código del país, sin espacios ni símbolos).

Ejemplo para Colombia: `573001234567`

## Personalización

### Colores
Edita `style.css` y busca la sección `:root` para cambiar:
- `--accent: #ff6b35` (Naranja principal)
- `--accent-dark: #d84315` (Naranja oscuro)
- `--promo: #ffd700` (Amarillo de promociones)

### Contenido
Edita `index.html` para cambiar:
- Nombres de productos
- Descripciones
- Precios
- Categorías
